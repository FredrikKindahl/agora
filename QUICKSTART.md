# Quick Start Guide 🚀

**Welcome to AGORA!** This guide gets you up and running in 5 minutes.

## What is This?

AGORA visualizes the gap between what people want and what politicians actually do. Think of it as a "democratic lie detector" that makes accountability visible.

---

## I Want To...

### 👀 See the Demo

1. Download/clone this repository
2. Open `index.html` in your browser
3. Click on a vote option
4. See the gap visualization!

**That's it!** No build process, no dependencies.

---

### 💻 Contribute Code

**First time?**

```bash
# 1. Fork the repo on GitHub (click the Fork button)

# 2. Clone YOUR fork
git clone https://github.com/YOUR-USERNAME/agora.git
cd agora

# 3. Create a branch
git checkout -b feature/my-awesome-feature

# 4. Make changes
# (edit files, test in browser)

# 5. Commit
git add .
git commit -m "Add my awesome feature"

# 6. Push
git push origin feature/my-awesome-feature

# 7. Open Pull Request on GitHub
```

**Read [CONTRIBUTING.md](CONTRIBUTING.md) for details!**

### 🌍 Translate

Make AGORA accessible in your language!

**Steps:**
1. Copy `lang/en.json` (coming soon)
2. Translate all strings to your language
3. Test the interface
4. Submit a pull request

Currently needed: Svenska, Español, Français, Deutsch, العربية, 中文, and more!
