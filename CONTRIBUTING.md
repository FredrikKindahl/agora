## 🚀 Getting Started

### 1. Fork & Clone
```bash
# Fork the repository on GitHub first, then:
git clone https://github.com/[your-username]/agora.git
cd agora
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
# or
git checkout -b fix/bug-description
```

### 3. Make Changes
- Write clean, readable code
- Follow existing code style
- Add comments for complex logic
- Test your changes thoroughly

### 4. Commit
```bash
git add .
git commit -m "Brief description of changes"

# Good commit messages:
# ✅ "Add Swedish parliament vote scraper"
# ✅ "Fix mobile layout on results page"
# ✅ "Translate interface to Spanish"
# ❌ "fixed stuff"
# ❌ "update"
```

### 5. Push & Pull Request
```bash
git push origin feature/your-feature-name
```

Then open a Pull Request on GitHub with:
- **Clear title** describing what you did
- **Description** explaining why and how
- **Screenshots** if UI changes
- **Testing notes** how you verified it works

## 📋 Development Guidelines

### Code Style
- **HTML**: Semantic, accessible markup
- **CSS**: Clear class names, organized by section
- **JavaScript**: Modern ES6+, commented for clarity
- **Keep it simple**: Readable code > clever code

### Accessibility
- All interactive elements must be keyboard accessible
- Use semantic HTML (`<button>`, `<nav>`, etc.)
- Include ARIA labels where needed
- Test with screen readers when possible

### Performance
- Optimize images
- Minimize JavaScript
- Test on slow connections
- Keep bundle sizes small

### Security
- Never commit secrets or API keys
- Validate all user input
- Follow security best practices
- Report security issues privately

## 🐛 Reporting Bugs

Found a bug? Help us fix it!

**Before reporting:**
1. Check if it's already reported in [Issues](https://github.com/[username]/agora/issues)
2. Try to reproduce it consistently
3. Note your browser/OS version

**When reporting:**
- **Title**: Clear, specific (e.g., "Vote buttons unresponsive on mobile Safari")
- **Description**: What happened vs. what should happen
- **Steps to reproduce**: Numbered list
- **Screenshots**: If helpful
- **Environment**: Browser, OS, device

## 💡 Suggesting Features

Have an idea? We'd love to hear it!

**Good feature requests include:**
- **Problem**: What issue does this solve?
- **Solution**: Your proposed feature
- **Alternatives**: Other ways to solve it
- **Use case**: Real-world example

**Note**: We prioritize features that:
- Advance the core mission (making gaps visible)
- Are accessible to all users
- Don't compromise privacy or security
- Are technically feasible with our resources

## 🌍 Translation Guidelines

Help make AGORA accessible globally!

**To add a new language:**
1. Copy `lang/en.json` to `lang/[language-code].json`
2. Translate all strings
3. Test the interface with your translations
4. Submit a Pull Request

**Translation tips:**
- Keep it natural, not literal
- Maintain tone (empowering, transparent, accessible)
- Test on actual users if possible
- Note any cultural considerations
